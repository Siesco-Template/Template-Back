## 🎯 Genel Bakış

Excel import işlemi 3 ana adımdan oluşur:

1. **Dosya Yükleme**: Excel dosyasını yükle ve preview al
2. **Column Mapping**: Excel column'larını table column'ları ile eşleştir
3. **Validation**: Verileri validate et ve valid kayıtları hazırla

**Not**: Validation tamamlandıktan sonra, valid kayıtlar mevcut Table insert endpoint'i ile kaydedilir.

**Base URL**: `http://localhost:5002/api/Excel` (Development)

## 📝 Import İşlem Adımları

### Adım 1: Excel Dosyası Yükleme

Kullanıcı Excel dosyasını seçer ve yükler. Backend dosyayı parse eder ve preview döner.

**Endpoint**: `POST /api/Excel/UploadFile`

**Request**:
- Content-Type: `multipart/form-data`
- Body: FormData ile `file` field'ı

**Response**:
```typescript
interface ExcelPreviewDto {
  headers: string[];                    // Excel'deki column isimleri
  records: Record<string, string>[];    // Excel'den gelen veriler (ilk 100 satır)
}
```

**Örnek Response**:
```json
{
  "headers": [
    "Göstəricilər",
    "Xərclərin iqtisadi təsnifat kodu",
    "Hesabat dövrü üçün təsdiq edilmiş smeta məbləği",
    "Kassa icrası",
    "Faktiki xərc"
  ],
  "records": [
    {
      "Göstəricilər": "1. İlkin əvvəlinə qalıq",
      "Xərclərin iqtisadi təsnifat kodu": "210000",
      "Hesabat dövrü üçün təsdiq edilmiş smeta məbləği": "0.00",
      "Kassa icrası": "0.00",
      "Faktiki xərc": "0.00"
    },
    // ... diğer kayıtlar (maksimum 100)
  ]
}
```

**Önemli Notlar**:
- Sadece `.xlsx` dosyaları kabul edilir
- Maksimum 1 dosya yüklenebilir
- Preview için maksimum 100 kayıt döner (configurable)
- Dosya boyutu limiti yoktur (tüm dosya işlenir, sadece preview 100 kayıt)

### Adım 2: Table Column'larını Alma ve Mapping

Table column'larını al ve Excel column'ları ile eşleştir.

#### 2.1. Table Column'larını Al

**Endpoint**: `GET /api/Excel/GetTableColumns?tableName={tableName}`

**Request**:
- Query Parameter: `tableName` (string) - Database table adı

**Response**:
```typescript
interface TableColumnDto {
  name: string;              // Column adı (property name)
  displayName: string;       // Display adı (genelde name ile aynı)
  dataType: string;          // Veri tipi: "string", "int", "decimal", "DateTime", "Guid", vb.
  isRequired: boolean;       // Zorunlu mu?
  maxLength?: number;        // Maksimum uzunluk (string için)
  isPrimaryKey: boolean;     // Primary key mi?
  foreignTable?: string;     // Foreign key ise, referans tablo adı
  foreignColumn?: string;    // Foreign key ise, referans column adı
  isAutoGenerated: boolean;  // Otomatik oluşturulan mu? (Identity/Auto-increment)
}
```

**Örnek Request**:
```
GET /api/Excel/GetTableColumns?tableName=Reports
```

#### 2.2. Otomatik Column Matching

Excel column isimleri ile table column isimlerini otomatik eşleştir. Detaylar için [Otomatik Column Matching](#otomatik-column-matching) bölümüne bakın.

**Mapping Formatı**:
```typescript
// Excel column adı -> Table column adı
const mappings: Record<string, string> = {
  "Göstəricilər": "Indicators",
  "Xərclərin iqtisadi təsnifat kodu": "EconomicClassificationCode",
  // ...
};
```

**Önemli Notlar**:
- `IsAutoGenerated: true` olan column'ları mapping'e eklemeyin (örn: Id)
- `IsPrimaryKey: true` ve `IsAutoGenerated: true` olan column'lar otomatik oluşturulur
- Mapping'de sadece Excel'de bulunan ve table'da olan column'lar olmalı

### Adım 3: Validation

Validation işlemi tamamlandıktan sonra, `isValid: true` olan kayıtlar mevcut Table insert endpoint'i ile kaydedilir.

**Endpoint**: `POST /api/Excel/Validate`

**Request**:
```typescript
interface ValidateRequestDto {
  tableName: string;                              // Table adı
  records: Record<string, string>[];              // Excel'den gelen tüm kayıtlar
  mappings: Record<string, string>;                // Excel column -> Table column mapping
}
```

**Örnek Request**:
```json
{
  "tableName": "Reports",
  "records": [
    {
      "Göstəricilər": "1. İlkin əvvəlinə qalıq",
      "Xərclərin iqtisadi təsnifat kodu": "210000",
      "Hesabat dövrü üçün təsdiq edilmiş smeta məbləği": "0.00",
      "Kassa icrası": "0.00",
      "Faktiki xərc": "0.00"
    }
    // ... tüm kayıtlar
  ],
  "mappings": {
    "Göstəricilər": "Indicators",
    "Xərclərin iqtisadi təsnifat kodu": "EconomicClassificationCode",
    "Hesabat dövrü üçün təsdiq edilmiş smeta məbləği": "ApprovedBudgetAmount",
    "Kassa icrası": "CashExecution",
    "Faktiki xərc": "ActualExpense"
  }
}
```

**Response**:
```typescript
interface ValidatedRecordDto {
  records: Record<string, string>;        // Mapped edilmiş kayıt (table column adları ile)
  isValid: boolean;                      // Bu kayıt geçerli mi?

}
```

**Örnek Response**:
```json

      "EconomicClassificationCode": "210000",

      "ActualExpense": "0.00"

    "isValid": true,

  },
  {

      "Indicators": "2. Test",
      "EconomicClassificationCode": "999999",
      "ApprovedBudgetAmount": "1000.50",
      "CashExecution": "500.25",
      "ActualExpense": "750.75"
    },
    "isValid": false,
    "errors": {

      ],

        "Dəyər maksimum 1000.00 ola bilər."
      ]
    }

```

**Validation Kuralları**:
- **Required**: `IsRequired: true` olan field'lar boş olamaz
- **MaxLength**: String field'lar için maksimum uzunluk kontrolü
- **DataType**: Veri tipi kontrolü (int, decimal, DateTime, Guid, vb.)
- **ForeignKey**: Foreign key field'lar için referans tabloda varlık kontrolü
- **Enum**: Enum field'lar için geçerli değer kontrolü

**Önemli Notlar**:
- Validation sonuçlarında `isValid: false` olan kayıtlar kırmızı ile işaretlenmelidir
- Her field için hata mesajları `errors` objesinde bulunur
- Frontend'de hatalı hücreler kırmızı arka plan ile gösterilmelidir
- Hover durumunda hata mesajları gösterilmelidir
- Validation tamamlandıktan sonra, sadece `isValid: true` olan kayıtlar mevcut Table insert endpoint'i ile kaydedilir
- `isAutoGenerated: true` olan column'ları (örn: Id) valid kayıtlardan çıkarmayın, backend otomatik oluşturur

## 🔄 Otomatik Column Matching

Excel column isimleri ile table column isimlerini otomatik eşleştirmek için aşağıdaki algoritmayı kullanın:

### Matching Algoritması

1. **Tam Eşleşme (Case-Insensitive)**
   ```typescript
   // Excel: "Göstəricilər" === Table: "Göstəricilər" ✅
   // Excel: "göstəricilər" === Table: "Göstəricilər" ✅
   ```

2. **Normalize Edilmiş Eşleşme**
   - Boşlukları kaldır
   - Özel karakterleri normalize et (ı->i, İ->I, ş->s, Ş->S, vb.)
   - Case-insensitive karşılaştır
   ```typescript
   // Excel: "Göstəricilər" -> "gostericiler"
   // Table: "Gostericiler" -> "gostericiler" ✅
   ```

3. **Kısmi Eşleşme (Benzerlik Skoru)**
   - Levenshtein distance veya benzerlik algoritması kullan
   - Benzerlik skoru > 0.8 ise eşleştir
   ```typescript
   // Excel: "Xərclərin iqtisadi təsnifat kodu"
   // Table: "EconomicClassificationCode"
   // Benzerlik skoru: 0.65 ❌ (eşleşmez)
   
   // Excel: "Economic Classification Code"
   // Table: "EconomicClassificationCode"
   // Benzerlik skoru: 0.95 ✅ (eşleşir)
   ```

### TypeScript Örnek Fonksiyon

```typescript
function normalizeString(str: string): string {
  return str
    .toLowerCase()
    .replace(/ı/g, 'i')
    .replace(/İ/g, 'i')
    .replace(/ş/g, 's')
    .replace(/Ş/g, 's')
    .replace(/ğ/g, 'g')
    .replace(/Ğ/g, 'g')
    .replace(/ü/g, 'u')
    .replace(/Ü/g, 'u')
    .replace(/ö/g, 'o')
    .replace(/Ö/g, 'o')
    .replace(/ç/g, 'c')
    .replace(/Ç/g, 'c')
    .replace(/\s+/g, '')
    .replace(/[^a-z0-9]/g, '');
}

function autoMatchColumns(
  excelHeaders: string[],
  tableColumns: TableColumnDto[]
): Record<string, string> {
  const mappings: Record<string, string> = {};
  const usedTableColumns = new Set<string>();

  // 1. Tam eşleşme (case-insensitive)
  for (const excelHeader of excelHeaders) {
    const tableColumn = tableColumns.find(
      col => col.name.toLowerCase() === excelHeader.toLowerCase() &&
             !usedTableColumns.has(col.name) &&
             !col.isAutoGenerated
    );
    if (tableColumn) {
      mappings[excelHeader] = tableColumn.name;
      usedTableColumns.add(tableColumn.name);
    }
  }

  // 2. Normalize edilmiş eşleşme
  for (const excelHeader of excelHeaders) {
    if (mappings[excelHeader]) continue; // Zaten eşleştirilmiş

    const normalizedExcel = normalizeString(excelHeader);
    const tableColumn = tableColumns.find(
      col => normalizeString(col.name) === normalizedExcel &&
             !usedTableColumns.has(col.name) &&
             !col.isAutoGenerated
    );
    if (tableColumn) {
      mappings[excelHeader] = tableColumn.name;
      usedTableColumns.add(tableColumn.name);
    }
  }

  // 3. Kısmi eşleşme (basit örnek - daha gelişmiş algoritma kullanılabilir)
  for (const excelHeader of excelHeaders) {
    if (mappings[excelHeader]) continue;

    const normalizedExcel = normalizeString(excelHeader);
    let bestMatch: TableColumnDto | null = null;
    let bestScore = 0;

    for (const tableColumn of tableColumns) {
      if (usedTableColumns.has(tableColumn.name) || tableColumn.isAutoGenerated) {
        continue;
      }

      const normalizedTable = normalizeString(tableColumn.name);
      const similarity = calculateSimilarity(normalizedExcel, normalizedTable);
      
      if (similarity > bestScore && similarity > 0.8) {
        bestScore = similarity;
        bestMatch = tableColumn;
      }
    }

    if (bestMatch) {
      mappings[excelHeader] = bestMatch.name;
      usedTableColumns.add(bestMatch.name);
    }
  }

  return mappings;
}

function calculateSimilarity(str1: string, str2: string): number {
  // Basit benzerlik hesabı (Levenshtein distance kullanılabilir)
  const longer = str1.length > str2.length ? str1 : str2;
  const shorter = str1.length > str2.length ? str2 : str1;
  
  if (longer.length === 0) return 1.0;
  
  const distance = levenshteinDistance(longer, shorter);
  return (longer.length - distance) / longer.length;
}

function levenshteinDistance(str1: string, str2: string): number {
  const matrix: number[][] = [];
  
  for (let i = 0; i <= str2.length; i++) {
    matrix[i] = [i];
  }
  
  for (let j = 0; j <= str1.length; j++) {
    matrix[0][j] = j;
  }
  
  for (let i = 1; i <= str2.length; i++) {
    for (let j = 1; j <= str1.length; j++) {
      if (str2.charAt(i - 1) === str1.charAt(j - 1)) {
        matrix[i][j] = matrix[i - 1][j - 1];
      } else {
        matrix[i][j] = Math.min(
          matrix[i - 1][j - 1] + 1,
          matrix[i][j - 1] + 1,
          matrix[i - 1][j] + 1
        );
      }
    }
  }
  
  return matrix[str2.length][str1.length];
}
```

## ⚠️ Hata Yönetimi

### HTTP Status Kodları

- **200 OK**: İşlem başarılı
- **400 Bad Request**: Geçersiz request (örn: eksik parametreler)
- **401 Unauthorized**: Authentication gerekli
- **404 Not Found**: Table bulunamadı
- **500 Internal Server Error**: Server hatası

### Hata Response Formatı

```typescript
interface ErrorResponse {
  error: string;
  message: string;
  details?: any;
}
```

**Örnek Hata Response**:
```json
{
  "error": "ValidationError",
  "message": "TableName dəyəri tələb olunur.",
  "details": null
}
```

### Frontend'de Hata Gösterimi

1. **Validation Hataları**: 
   - Hatalı hücreler kırmızı arka plan ile gösterilmeli
   - Hover durumunda hata mesajları gösterilmeli
   - Hatalı satırlar belirgin şekilde işaretlenmeli

2. **API Hataları**:
   - Network hataları için kullanıcıya bilgi verilmeli
   - Validation hataları için detaylı mesajlar gösterilmeli
   - Retry mekanizması eklenebilir

## 💻 TypeScript/JavaScript Örnekleri

### Tam Import İşlemi Örneği

```typescript
import axios from 'axios';

const API_BASE_URL = 'http://localhost:5002/api/Excel';

interface ExcelPreviewDto {
  headers: string[];
  records: Record<string, string>[];
}

interface TableColumnDto {
  name: string;
  displayName: string;
  dataType: string;
  isRequired: boolean;
  maxLength?: number;
  isPrimaryKey: boolean;
  foreignTable?: string;
  foreignColumn?: string;
  isAutoGenerated: boolean;
}

interface ValidatedRecordDto {
  records: Record<string, string>;
  isValid: boolean;
  errors: Record<string, string[]>;
}

class ExcelImportService {
  /**
   * Adım 1: Excel dosyasını yükle ve preview al
   */
  async uploadFile(file: File): Promise<ExcelPreviewDto> {
    const formData = new FormData();
    formData.append('file', file);

    const response = await axios.post<ExcelPreviewDto>(
      `${API_BASE_URL}/UploadFile`,
      formData,
      {
        headers: {
          'Content-Type': 'multipart/form-data',
        },
      }
    );

    return response.data;
  }

  /**
   * Adım 2.1: Table column'larını al
   */
  async getTableColumns(tableName: string): Promise<TableColumnDto[]> {
    const response = await axios.get<TableColumnDto[]>(
      `${API_BASE_URL}/GetTableColumns`,
      {
        params: { tableName },
      }
    );

    return response.data;
  }

  /**
   * Adım 3: Verileri validate et
   */
  async validateRecords(
    tableName: string,
    records: Record<string, string>[],
    mappings: Record<string, string>
  ): Promise<ValidatedRecordDto[]> {
    const response = await axios.post<ValidatedRecordDto[]>(
      `${API_BASE_URL}/Validate`,
      {
        tableName,
        records,
        mappings,
      }
    );

    return response.data;
  }

  /**
   * Tam import işlemi (validation'a kadar)
   */
  async importExcel(
    file: File,
    tableName: string,
    onProgress?: (step: string, progress: number) => void
  ): Promise<{
    preview: ExcelPreviewDto;
    tableColumns: TableColumnDto[];
    mappings: Record<string, string>;
    validationResults: ValidatedRecordDto[];
    validRecords: Record<string, string>[];
  }> {
    try {
      // Adım 1: Dosya yükle
      onProgress?.('Dosya yükleniyor...', 10);
      const preview = await this.uploadFile(file);

      // Adım 2: Table column'larını al
      onProgress?.('Table column\'ları alınıyor...', 30);
      const tableColumns = await this.getTableColumns(tableName);

      // Adım 2.2: Otomatik matching
      onProgress?.('Column\'lar eşleştiriliyor...', 40);
      const mappings = autoMatchColumns(preview.headers, tableColumns);

      // Adım 3: Validation
      onProgress?.('Veriler kontrol ediliyor...', 60);
      const validationResults = await this.validateRecords(
        tableName,
        preview.records,
        mappings
      );

      // Sadece valid kayıtları filtrele
      const validRecords = validationResults
        .filter(result => result.isValid)
        .map(result => result.records);

      onProgress?.('Tamamlandı!', 100);

      return {
        preview,
        tableColumns,
        mappings,
        validationResults,
        validRecords,
      };
    } catch (error) {
      if (axios.isAxiosError(error)) {
        throw new Error(
          error.response?.data?.message || error.message || 'Bilinmeyen hata'
        );
      }
      throw error;
    }
  }
}

// Kullanım örneği
const importService = new ExcelImportService();

const handleFileUpload = async (file: File, tableName: string) => {
  try {
    const result = await importService.importExcel(
      file,
      tableName,
      (step, progress) => {
        console.log(`${step} (${progress}%)`);
        // UI'da progress bar güncelle
      }
    );

    console.log(`Validation tamamlandı. ${result.validRecords.length} geçerli kayıt bulundu.`);
    
    // Valid kayıtları mevcut Table insert endpoint'i ile kaydet
    // Örnek: await tableService.insertRecords(tableName, result.validRecords);
  } catch (error) {
    console.error('Import hatası:', error);
    // Hata mesajını kullanıcıya göster
  }
};
```

### React Hook Örneği

```typescript
import { useState } from 'react';
import { ExcelImportService } from './ExcelImportService';

export const useExcelImport = (tableName: string) => {
  const [loading, setLoading] = useState(false);
  const [progress, setProgress] = useState(0);
  const [currentStep, setCurrentStep] = useState('');
  const [error, setError] = useState<string | null>(null);
  const [preview, setPreview] = useState<ExcelPreviewDto | null>(null);
  const [tableColumns, setTableColumns] = useState<TableColumnDto[]>([]);
  const [mappings, setMappings] = useState<Record<string, string>>({});
  const [validationResults, setValidationResults] = useState<ValidatedRecordDto[]>([]);

  const importService = new ExcelImportService();

  const uploadFile = async (file: File) => {
    setLoading(true);
    setError(null);
    try {
      setCurrentStep('Dosya yükleniyor...');
      setProgress(10);
      const previewData = await importService.uploadFile(file);
      setPreview(previewData);

      setCurrentStep('Table column\'ları alınıyor...');
      setProgress(30);
      const columns = await importService.getTableColumns(tableName);
      setTableColumns(columns);

      setCurrentStep('Column\'lar eşleştiriliyor...');
      setProgress(40);
      const autoMappings = autoMatchColumns(previewData.headers, columns);
      setMappings(autoMappings);

      setCurrentStep('Veriler kontrol ediliyor...');
      setProgress(60);
      const validation = await importService.validateRecords(
        tableName,
        previewData.records,
        autoMappings
      );
      setValidationResults(validation);

      setProgress(100);
      return { previewData, columns, autoMappings, validation };
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Bilinmeyen hata');
      throw err;
    } finally {
      setLoading(false);
    }
  };

  const getValidRecords = () => {
    return validationResults
      .filter(result => result.isValid)
      .map(result => result.records);
  };

  return {
    loading,
    progress,
    currentStep,
    error,
    preview,
    tableColumns,
    mappings,
    setMappings,
    validationResults,
    uploadFile,
    getValidRecords,
  };
};
```

## ❓ Sık Sorulan Sorular

### 1. Excel dosyasında kaç satır olabilir?

- **Preview**: Maksimum 100 satır döner (configurable)
- **Import**: Tüm satırlar işlenir, sınır yoktur
- **Validation**: Tüm satırlar validate edilir
- **Save**: Tüm valid satırlar kaydedilir

### 2. Hangi Excel formatları desteklenir?

- Sadece `.xlsx` formatı desteklenir
- `.xls` formatı desteklenmez

### 3. Mapping'i manuel olarak değiştirebilir miyim?

Evet! Otomatik matching sonrası kullanıcı mapping'leri manuel olarak değiştirebilir. `mappings` objesini güncelleyip tekrar validation yapın.

### 4. Validation'dan geçmeyen kayıtlar ne olur?

- Validation'dan geçmeyen kayıtlar (`isValid: false`) kaydedilmez
- Sadece `isValid: true` olan kayıtlar mevcut Table insert endpoint'i ile kaydedilir
- Hatalı kayıtlar frontend'de kırmızı ile işaretlenir ve kullanıcıya gösterilir

### 5. Auto-generated column'ları (Id gibi) mapping'e eklemeli miyim?

**Hayır!** `IsAutoGenerated: true` olan column'ları mapping'e eklemeyin. Backend otomatik olarak oluşturur.

### 6. Foreign key validation nasıl çalışır?

- Foreign key field'lar için referans tabloda değerin varlığı kontrol edilir
- Eğer değer referans tabloda yoksa validation hatası döner
- Hata mesajı: `"'value' dəyəri 'TableName.ColumnName' cədvəlində tapılmadı."`

### 7. Valid kayıtları nasıl kaydederim?

- Validation tamamlandıktan sonra, `isValid: true` olan kayıtları filtreleyin
- Bu kayıtları mevcut Table insert endpoint'inize gönderin
- Table insert endpoint'i transaction yönetimini yapar

### 8. Büyük dosyalar için performans nasıl?

- Validation işlemi tüm kayıtlar için yapılır (async)
- Büyük dosyalar için progress indicator gösterilmesi önerilir
- Valid kayıtları kaydetmek için mevcut Table insert endpoint'inizi kullanın
